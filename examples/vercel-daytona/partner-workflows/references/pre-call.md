# Pre-call brief

Resolve the upcoming call, current local time, matter, and actual last engagement. If the call is near, deliver a useful brief from the evidence already available before attempting a broad archive search. State important coverage gaps briefly.

Fit these into one message, using one line per topic where possible:

**[Matter] · [call time]**

- **Status:** Deal stage and nearest consequential milestone.
- **Changed:** Material changes since the partner's last evidenced engagement, with date. Omit routine correspondence.
- **Other side:** Current asks and leverage, including unresolved positions in the latest redline.
- **Associate:** The specific blocker and what would unblock it; identify the owner if known.
- **Client:** Explicit concerns first. If tone or frequency suggests concern, mark it as an inference and cite the relevant messages and observed window. Do not diagnose anxiety or infer it from one terse email. Compare frequency only against an observed baseline.
- **Your decisions:** Two or three actual choices reserved for the partner, with options and trade-offs grounded in the record. Fewer if fewer exist; never invent choices to fill a quota.

Mark unknown sections as "Not confirmed" only when the missing information matters. Do not fabricate an associate blocker or counterparty position.

For scheduled checks, read the calendar afresh. Only brief upcoming, non-cancelled client calls that need preparation. Use event ID plus start time and source versions to check prior delivery. Do not repeat a delivered brief on every poll. A reschedule or material change may justify a concise update; a formatting change does not. A call outside the 15-minute window receives no notification. Do not equate a calendar invitation with a confirmed meeting attendance record.
